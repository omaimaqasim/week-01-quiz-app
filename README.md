# 🧠 SmartQuiz – Interactive Quiz  

A simple and fun **4-option quiz game** built with HTML, CSS, and JavaScript.  

## 📌 Features  
- 10 multiple-choice questions.  
- Score tracker & progress bar with animation.  
- Instant feedback (green = correct, red = wrong).  
- Final result with message & restart option. 
- good UIUX with blue theme and hover effect btns.


## 🛠️ Tech Used  
- HTML, CSS, JavaScript  

## 📂 Run Project  
1. Clone repo  
2. Open `index.html` in browser
